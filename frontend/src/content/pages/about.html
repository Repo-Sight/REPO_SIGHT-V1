About REPO-SIGHT

Last updated: October 19, 2026

REPO-SIGHT is a free static code analysis tool. Paste a public GitHub URL for a C++, Python, Java, TypeScript, JavaScript, or C# repository, and it reports size, structure, complexity, duplication, security hotspots, technical debt, and rule violations in seconds — no account, no signup, no paywall.

What it does

The engine behind REPO-SIGHT is a deterministic, five-stage pipeline — scan, lex, parse, aggregate, report — the same one the cma binary runs from the command line. It checks 98 rules across all six supported languages, flags duplicated code and security hotspots, and can correlate an uploaded LCOV coverage report against the files that need it most, all rolled up into a single project health score. Sign in and it also keeps your last five scans and shows what changed since the previous one, so you can see whether a codebase is actually improving.

Who it's for

REPO-SIGHT is built for solo developers, students, job seekers, and small teams — the people shipping code fast, often with the help of an AI coding assistant, who don't have a platform team or an engineering manager already running SonarQube on their behalf.

Why it exists

Most static analysis tools are built for teams — they assume a CI pipeline, a paid seat per developer, and someone whose job is to read the dashboard. REPO-SIGHT exists for the case those tools tend to ignore: a student, a job seeker, or a solo developer who wants an honest, specific read on a codebase right now, without signing up for anything or waiting on a sales call.

Supported languages

C++, Python, Java, TypeScript, JavaScript, and C#. Each language has its own lexer, parser, and rule set, tuned to that language's own common pitfalls rather than one generic rule set stretched across all six.

What makes it different

REPO-SIGHT isn't an AI code reviewer guessing at what looks wrong in a diff — it's a real parsing engine computing the same metrics a senior engineer would check by hand (cyclomatic complexity, nesting depth, function length, comment density), and for public repositories it doesn't require an account, a GitHub App install, or a credit card to see the result.

Limitations

  • Only the six languages above are analyzed — files in any other language are skipped, not silently miscounted.
  • Public repositories are scanned from their main or master branch. Private repositories can be scanned if you sign in with GitHub and install the REPO-SIGHT GitHub App on that repository, and are scanned from the default branch. Other branches aren't supported yet.
  • Metrics and findings are heuristic indicators of maintainability and common risk patterns. The security checks are pattern-based hotspots, not a full security audit, a correctness proof, or a substitute for human code review.
  • Very large repositories can exceed the analysis time budget and time out rather than return a partial report.

Who builds it

How it's funded

REPO-SIGHT is free to use, with no paid tier. A small amount of advertising, served through Google AdSense, supports hosting and infrastructure costs — and optional donations through Buy Me a Coffee help too. A single flat-fee “Supported by” spot is also available to sponsors. No usage limits, no feature paywall, no credit card.
