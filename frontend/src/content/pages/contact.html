Contact

Bug reports, feature requests, and general questions

REPO-SIGHT is built and maintained by one person, so replies aren't instant, but every message gets read.

Email

The fastest way to reach us: contact.reposight@gmail.com

Found a bug in a scan?

Include the repository URL you scanned and, if you have it, the scan ID from the URL bar (the part after ?scan=) — it makes tracking down what went wrong much faster.

Feature requests

REPO-SIGHT is actively developed in public. If there's a language, metric, or view you wish it had, say so — feature requests directly shape the roadmap.

In-app feedback

The dashboard also has a lightweight feedback widget for quick, in-context notes without leaving the report you're looking at.
