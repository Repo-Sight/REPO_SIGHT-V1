Fix first

The report opens with the problems worth your time, grouped by cause and ranked, instead of a flat list of 298 lines. For this scan the top two were:

  1. Empty error handler (high tier, high confidence). Six catch blocks in three JavaScript files do nothing with the error, so failures would vanish silently. Fix: log it, handle it, or add a comment saying why ignoring it is intended.
