Five stages. One pass. No black box.

Every file goes through the same deterministic pipeline — the same one the cma binary runs on the command line.

01

Scan

Finds every recognized source file across all six supported languages, in a repo, a folder, or a single file.

02

Lex

Character-level tokenizer per language. Keywords, identifiers, literals, operators — no regex, no compiler.

03

Parse

Walks the token stream to find functions, classes, nesting depth, and cyclomatic complexity.

04

Aggregate

Per-file metrics, duplication, and rule violations roll up into one project-level report and health score.

05

Report

A dashboard you can read — never a black box.
