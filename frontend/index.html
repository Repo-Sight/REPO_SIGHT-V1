Five stages. One pass. No black box.

Every file goes through the same deterministic pipeline — the same one the cma binary runs on the command line.

01

Scan

Finds every recognized source file across all six supported languages, in a repo, a folder, or a single file.

02

Lex

Character-level tokenizer per language. Keywords, identifiers, literals, operators — no regex, no compiler.

03

Parse

Walks the token stream to find functions, classes, nesting depth, and cyclomatic complexity.

04

Aggregate

Per-file metrics, duplication, and rule violations roll up into one project-level report and health score.

05

Report

A dashboard you can read — never a black box.

Advertisement

Every metric the engine computes — one dashboard.

Six languages, one report. Everything below runs on the same free scan, no tier gating.

Size & structure

Lines, functions, classes, and imports — split by real code vs. comments vs. blank, rolled up project-wide.

Complexity

Cyclomatic complexity, max nesting depth, loops and conditions, and your longest function.

Technical debt

Every TODO and FIXME marker, counted — so nothing quietly rots in a comment.

Duplication

Token-based clone detection finds copy-pasted blocks across your whole codebase, not just per file.

Security hotspots

80 rules across all six languages flag risky patterns — rolled up by severity, not just line count.

Coverage

Upload an LCOV report from your own CI run and see line coverage mapped against the files that need it most.

Scan-over-scan tracking

Sign in and REPO-SIGHT remembers your last scan of a repo, so you can see if it's actually improving.

AI explain-this-finding

Signed-in users can ask for a plain-English explanation of any specific finding, not just the raw rule text.
