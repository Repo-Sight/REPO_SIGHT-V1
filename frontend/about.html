About REPO-SIGHT

Last updated: September 16, 2026

REPO-SIGHT is a free static code analysis tool. Paste a public GitHub URL for a C++, Python, Java, TypeScript, JavaScript, or C# repository, and it reports size, structure, complexity, duplication, security hotspots, technical debt, and rule violations in seconds — no account, no signup, no paywall.

What it does

The engine behind REPO-SIGHT is a deterministic, five-stage pipeline — scan, lex, parse, aggregate, report — the same one the cma binary runs from the command line. It checks 39 rules across all six supported languages, flags duplicated code and security hotspots, and can correlate an uploaded LCOV coverage report against the files that need it most, all rolled up into a single project health score. Sign in and it also remembers your last scan of a repo, so you can see whether a codebase is actually improving.

Why it exists

Most static analysis tools are built for teams — they assume a CI pipeline, a paid seat per developer, and someone whose job is to read the dashboard. REPO-SIGHT exists for the case those tools tend to ignore: a student, a job seeker, or a solo developer who wants an honest, specific read on a codebase right now, without signing up for anything or waiting on a sales call.

Who builds it

REPO-SIGHT is built and maintained by Ronak Arora, a solo developer. The project is open source under the Apache 2.0 License, and the source is publicly available on GitHub.

How it's funded

REPO-SIGHT is free to use, with no paid tier. A small amount of advertising, served through Google AdSense, supports hosting and infrastructure costs — that's the whole business model. No usage limits, no feature paywall, no credit card.
