About REPO-SIGHT

Last updated: August 31, 2026

REPO-SIGHT is a free static code analysis tool. Paste a public GitHub URL for a C++, Python, or Java repository, and it reports size, structure, complexity, technical debt, and rule violations in seconds — no account, no signup, no paywall.

What it does

The engine behind REPO-SIGHT is a deterministic, five-stage pipeline — scan, lex, parse, aggregate, report — ... 21 rule checks across the three supported languages, rolled up into a single project health score.

Why it exists

Most static analysis tools are built for teams ... REPO-SIGHT exists for that second case ...

Who builds it

REPO-SIGHT is built and maintained by Ronak Arora, a solo developer. The project is open source under the Apache 2.0 License, and the source is publicly available on GitHub.

How it's funded

REPO-SIGHT is free to use, with no paid tier. A small amount of advertising, served through Google AdSense, supports hosting and infrastructure costs ...
