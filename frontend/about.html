About REPO-SIGHT

Last updated: September 6, 2026

REPO-SIGHT is a free static code analysis tool. Paste a public GitHub URL for a C++, Python, or Java repository, and it reports size, structure, complexity, technical debt, and rule violations in seconds — no account, no signup, no paywall.

What it does

The engine behind REPO-SIGHT is a deterministic, five-stage pipeline — scan, lex, parse, aggregate, report. It tokenizes and parses your source with hand-written lexers and parsers (no LLM guessing at code quality), counts functions, classes, loops, branches, and nesting depth, and checks the result against 21 static rules across the three supported languages. Everything rolls up into a single project health score and a plain metrics dashboard — no dependency graph you have to learn to read first.

Who it's for

REPO-SIGHT is built for solo developers, students, job seekers, and small teams — the people shipping code fast, often with the help of an AI coding assistant, who don't have a platform team or an engineering manager already running SonarQube on their behalf.

Why it exists

Most static analysis tools are built for teams: they need a build pipeline, a login, a per-seat license, or a dashboard designed for an engineering manager tracking ten other people's commits. REPO-SIGHT exists for the other case — one person who wants an honest read on their own repository, right now, without signing up for anything.

Supported languages

C++, Python, and Java today. Each language has its own lexer, parser, and rule set (7 rules per language), tuned to that language's own common pitfalls rather than one generic rule set stretched across all three.

What makes it different

REPO-SIGHT isn't an AI code reviewer guessing at what looks wrong in a diff — it's a real parsing engine computing the same metrics a senior engineer would check by hand (cyclomatic complexity, nesting depth, function length, comment density), and it doesn't require an account, a GitHub App install, or a credit card to see the result.

Limitations

  • Only C++, Python, and Java are analyzed today — files in any other language are skipped, not silently miscounted.
  • Only public GitHub repositories on the main/master branch are supported; private repos and other branches aren't yet.
  • Metrics are heuristic indicators of maintainability, not a security scan, a correctness proof, or a substitute for human code review.
  • Very large repositories can exceed the analysis time budget and time out rather than return a partial report.

Who builds it

REPO-SIGHT is built and maintained by Ronak Arora, a solo developer. The project is open source under the Apache 2.0 License.

How it's funded

REPO-SIGHT is free to use, with no paid tier. A small amount of advertising, served through Google AdSense, supports hosting and infrastructure costs so the tool can stay free and signup-free.
