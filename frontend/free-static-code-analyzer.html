Frequently asked questions

Is it free forever, or a free trial?

Free, full stop — there's no trial period and no paid tier to upgrade to. A small amount of advertising covers hosting instead.

Is there a repo size limit?

Very large repositories can exceed the analysis time budget and time out rather than return a partial report — it's best for repos that analyze in under a minute.

What's the catch?

Ads. That's the entire business model — see the about page for the full explanation.

Do I need to install anything?

No. Everything runs server-side from the GitHub URL you paste.
